# Pane 语音提问预览

在迷你聊天或完整聊天的输入框中点击麦克风，开始录音。点 **结束录音** 后转写会填入当前编辑框，可以先修改或继续输入，再点 **发送**。如果启用了 **朗读语音回答**，Pane 会在回答生成完毕后朗读。录音、转写和朗读状态都显示在输入框旁。

在 **设置 → 语音** 分别选择 Windows 麦克风、朗读设备和听写语言。两项设备设置默认跟随 Windows。拔插设备后可点击刷新。上次所选设备不可用时，Pane 保留该选择并在使用时提示，可手动切换到可用设备或系统默认设备。

Windows 原生辅助进程通过 WASAPI 读取或播放 PCM，听写和合成由本地 System.Speech 完成。仅在用户点击麦克风后录音，每次最多 11 秒。音频不上传，不写盘。发送语音转写时只提交用户确认后的文字，已有手动截图保持在输入框。隐藏聊天窗口会释放音频资源，已经提交的回答仍可在历史中查看。锁屏、休眠和退出沿用既有桌面安全策略。

## 接口

- `voice:devices` 返回 Windows 当前有效的输入和输出端点。设置只存储设备 ID、听写语言和朗读偏好。
- `voice:start` 只允许可见且已聚焦的 Pane 聊天主窗口调用。它返回经本地转写的草稿。`voice:finish` 结束录音并开始转写。`voice:cancel` 取消录音、转写或朗读。
- `chat:sendVoice` 使用当前对话和原有 Chat 连接发送确认后的文字。主进程基于请求和对话 ID 判断能否播放对应回答。
- `audio-list`、`audio-record`、`audio-play` 与原有截图辅助命令共用可执行文件。音频和文本只通过管道传递。

听写依赖 Windows 已安装的 System.Speech 语音识别器，语言包可用性因 Windows 版本和安装情况而异。当前模式为逐轮录音和朗读。

# Pane 3.5.0 全局划词

在其他应用选中文字后，按 **Ctrl+Shift+Q**。工具栏支持翻译、解释、问 AI 和更多操作。问 AI 可先输入自己的问题。回答在原位流式显示，也可打开完整对话。翻译目标可在设置或工具栏选择简体中文或英文。

设置中的自动划词默认关闭。启用后，原生进程监听当前前台窗口的 UI Automation 文本选择事件。只在同一前台窗口的左键拖动结束时用鼠标释放信号补充，不保存按键、坐标轨迹或选区日志。主进程合并相近事件，查询最短间隔 400 毫秒，UIA 查询上限 1.8 秒。

原生模块只调用 TextPattern 的 GetSelection，并核对前台窗口身份、焦点及选区。拒绝密码控件、受保护窗口和禁止名单中的应用。超过 3000 个 Unicode 码点提示缩小选区。手动快捷键读取失败时，只有主动点击导入按钮才读取剪贴板，不修改剪贴板内容。选区与回答卡片会随工具栏关闭清空，明确提交后的聊天仍正常生成和保存。

## 接口

- 原生 `selection` 返回已验证目标和选区状态，成功时返回文字与物理像素矩形。参数沿用当前助手 PID 与禁止应用名单。调用者必须设置超时。
- 原生 `selection-watch` 通过标准输出发送 `focus`、`selection`、`drag`、`click`。事件不包含文字、坐标或按键。
- 独立工具栏只暴露 `window.paneSelection`，支持 `state`、`import`、`details`、`submit`、`expand`、`close` 和订阅显示状态。主进程验证注册窗口、文档和主 frame。
- `InputRouter.external` 负责选择或复用现有对话，序列化外部参考数据并经 Chat 提交。文字作为不可信的用户引用处理。选中同一绑定窗口才可勾选图像，随后经 CaptureResolver 读取当轮截图。未勾选时不会附图。

定位尽量避开所有可见选区矩形，并以目标显示器 DIP 工作区约束。找不到不挡选区的空间时不展示。窗口焦点切换、外部点击或显式关闭可以清空选区。自动模式的 Esc 需要工具栏先取得焦点。受保护的控件与不提供 TextPattern 的程序不会以截图替代文字。

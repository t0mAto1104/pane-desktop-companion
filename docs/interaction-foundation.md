# Pane 3.4.1 交互基础

`main.ts` 保留窗口、托盘和服务的组装。InputRouter 按输入创建可信的交互上下文，并调用原有 CaptureResolver 和 Chat。InputSessionController 只管理发送前的准备阶段，同一时刻只允许一个准备任务，负责取消和 15 秒上限。生成期间的取消继续由 Chat 处理。

交互上下文由主进程绑定目标窗口、对话和截图标识。手动截图只可用于同一窗口身份。收起面板会停止普通截图工作，正在准备的发送仍保留已确认的附件，已经发送的回答继续生成。切换绑定、锁屏、休眠及退出会取消相关准备工作。PermissionManager 提供渲染进程主 frame 检查并保持现有默认拒绝媒体和其他权限的行为。

旧消息和数据库模式维持兼容。ChatGPT 与 API Key 继续调用原有服务。此阶段为后续划词与语音提供接入点。

# Pane 浮动角色

轨道机器人是默认外观。三个角色通过内置 ImageGen 生成，应用使用保留透明通道的 PNG。三款角色共享同一套聊天、截图和指导功能。

| 外观 | 设计取向 | 图片 |
| --- | --- | --- |
| 轨道机器人 | 紫白外壳、深色面罩和青色像素眼睛 | [orbit.png](../src/renderer/public/companion/orbit.png) |
| 灯笼狐 | 暖橙毛色、卷尾和紫色罗盘饰物 | [fox.png](../src/renderer/public/companion/fox.png) |
| 苔云 | 薄荷绿云朵、两片叶子和浅黄色脸颊 | [moss.png](../src/renderer/public/companion/moss.png) |

## 生成提示

### Pocket Orbit

> Design one production-ready original cartoon mascot sprite for Pane, a Windows desktop AI helper. Design name: Pocket Orbit. A tiny hovering rounded-square robot with lavender-white ceramic housing, dark charcoal soft rectangular face display and two bright cyan pixel eyes, violet top fin, small floating white hands close to the body. Contemporary flat-shaded digital cartoon with soft, crisp dark-purple edging and minimal specular highlights. Calm and observant expression, strong original friendly silhouette that can be recognized at 64 px. 1024 × 1024 square output, isolated cropped close to the silhouette with clean true transparent alpha and about 10% safe margin. No ground, background, shadow on ground, text, logo, menus, UI mockup, extra objects, border or other poses. It should be an immediately usable desktop sprite, front-facing three-quarter view. Do not imitate an existing mascot.

### Lantern Fox

> Create a single original desktop AI companion sprite for Pane on Windows. Design name: Lantern Fox. An inviting terracotta-orange pocket fox with tall dark-tipped ears, creamy face and belly, a large single tail curling neatly beside its seated body, simple navy eyes, and one small violet compass-shaped charm with no lettering. Flat-shaded editorial cartoon, strong clean silhouette and readable detail at 64 px, softly rounded rather than babyish. Palette terracotta, oatmeal, purple, dark aubergine. Front three-quarter pose. 1024 × 1024 square image with true transparent alpha, tight framing and about 10% empty margin around the one character. No text, ground, shadow on ground, scene, props, outline bordering frame, UI, or other poses. Original character design.

### Moss Cloud

> Create a production-ready original desktop mascot sprite for Pane, a Windows AI desktop helper. Design name: Moss Cloud. A compact pale-mint cloud creature with a three-lobed rounded silhouette and two small teardrop feet, two deep-teal oval eyes and a small soft-green two-leaf sprout on its head leaning slightly to the right. One light butter-yellow cheek accent on each side. Sophisticated flat-shaded cartoon, clean soft dark-teal contour, visibly different from a robot and a fox, extremely clear at 64 px, friendly quietly curious mood. Front-facing stationary pose. A single sprite in a 1024 × 1024 square with genuine transparent alpha, tight framing plus 10% empty margin all around. No text, logo, background, ground, cast shadow, UI mockup, props, sparkles, or other poses.
